# تطبيق نومك (Nomak) — مشروع أندرويد لحساب دورات النوم

يحتوي هذا المجلد على المشروع المصدري الكامل لتطبيق **نومك لحساب دورات النوم** للأندرويد (Kotlin + Android WebView) مع دعم العمل التام وتخزين السجل محلياً.

## الطريقة الأولى: استخراج ملف APK عبر Android Studio
1. افتح برنامج **Android Studio** واختر **Open** ثم حدد مجلد هذا المشروع بعد فك الضغط.
2. انتظر بضع ثوانٍ حتى تكتمل مزامنة ملفات **Gradle Sync**.
3. من القائمة العلوية اختر:
   `Build > Build Bundle(s) / APK(s) > Build APK(s)`
4. ستجد ملف الـ APK الجاهز للتثبيت على هاتفك في المسار:
   `app/build/outputs/apk/debug/app-debug.apk`

## الطريقة الثانية: استخراج ملف APK سحابياً بدون تثبيت برامج (عبر GitHub Actions)
1. أنشئ مستودعاً جديداً (Repository) على حسابك في **GitHub** وارفع ملفات هذا المجلد إليه.
2. انتقل إلى تبويب **Actions** داخل المستودع؛ ستجد مهمة **Build Android APK** تعمل تلقائياً.
3. بعد انتهاء البناء (خلال دقيقتين تقريباً)، اضغط على المهمة وحمّل ملف `nomak-sleep-calculator-apk` الذي يحتوي على ملف `app-debug.apk` الجاهز للتثبيت.
